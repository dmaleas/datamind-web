## Virtual machine recovery

When data must be recovered from a VMware ESX/ESXi server, it is essential to engage engineers with in-depth knowledge of VMFS as well as of SAN and RAID technologies. Datamind has the necessary expertise to assist you.

## Supported technologies

- **Virtual infrastructure:** VMware, Microsoft Hyper-V, Citrix and Linux XEN, Oracle VM
- **File systems:** VMFS, NTFS, FAT, EXT3/4, HFS

## Important

In the event of formatting, deletion or partial corruption of virtual machine files (vmdk), **shut down the server hosting the virtual machines immediately**. If this is not possible, keep read and write activity to an absolute minimum.
